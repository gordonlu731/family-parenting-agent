# 真实模型场景验收

family-scenarios.json含20条虚构用例，初始状态均为not_run。这是后续人工/端到端验收清单，不是模型质量已通过的证明。现有48项自动测试采用模拟模型响应。

固定测试日期、页面日期、已确认的虚构宝宝档案、模型名称及配置；日期用例按固定上海日期计算预期。记录实际提案/问题、确认前后数据库变化、响应耗时、使用量、通过/失败及原因。重复提交须固定请求编号；跨成员和多设备用独立身份。失败响应通过可控测试代理或模拟供应商注入，不改生产凭证。

只有在已鉴权的隔离测试家庭中调用API；模型输出须经过页面核对。真实执行可能产生API费用，不由CI自动调用，不使用真实家庭健康记录。准确率、配料安全和采购数量须人工复核。尤其关注中文日期、拒吃和更正；不得只检查HTTP 200。

浏览器、真实模型、ECS和微信验收分别记录，任何一项通过均不替代其他项。
