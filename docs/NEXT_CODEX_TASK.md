## B 真实模型与完整文字闭环

1. 只检查本项目安全配置是否具备MODEL_API_KEY/BASE_URL/ID等，不输出值，不读取其他项目的密钥。默认沿用已有兼容接口；若需要调整型号/地域，先以所选供应商官方文档核实JSON模式、思考参数和输出限制。
