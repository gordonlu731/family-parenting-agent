## 可直接执行的项目工具

prepare_family_trial.py准备独立正式配置、初始化凭证、数据/备份目录和候选unit，**不启动、不建家、不安装unit**。要求独立源码/venv/dist都已准备，配置源为当前私有.env；只继承模型配置和限额，生成新的BOOTSTRAP_TOKEN。文件600、目录700。重复执行保留身份，发现非空数据目录、符号链接或不安全权限即拒绝。

```bash
python scripts/prepare_family_trial.py \
  --root /private/formal-release --data /private/formal-data \
  --backups /private/formal-backups --state /private/trial-state \
  --source-env /private/current-release/.env
```

域名未确定时只准备回环候选配置；确定后由执行者保留原候选配置，仅修改PUBLIC_ORIGIN/COOKIE_SECURE并重新生成、核验候选。不要覆盖新初始化凭证，不重新运行首次建家。直接用新候选目录且提供--domain也可生成HTTPS/Caddy候选；域名必须是DNS名称，不接受协议/路径/脚本内容。

## HTTPS唯一外部决策包

用户提供一个实际控制的域名及DNS操作条件，确认是否授权管理员为该域名部署HTTPS代理和80/443入站。当前未取得域名或这项系统/公网授权，执行者不能代买域名或猜DNS账号。

管理员收到的最小变更范围：

1. DNS将确认域名指向本ECS；选择已有代理或审核安装Caddy。只增加该站点，保留其他服务配置；应用18080维持回环，不加公网规则。
2. 审阅候选Caddyfile。独占新代理示例关闭admin API；如共享代理，保留原全局选项，只合并本站点，不能整体覆盖原配置。先`caddy validate --config <candidate>`，再按现有服务方式启动/重载。未安装Caddy时先审核包源与安装，不盲执行包管理命令。
3. 确认80/443入站和证书签发条件。切应用配置前备份；将候选PUBLIC_ORIGIN设为准确https origin、COOKIE_SECURE=true，使用已验证HTTPS启动器校验。
4. 从服务器外执行`python scripts/check_https.py --origin https://<confirmed-domain>`：严格系统CA校验、健康、禁演示、匿名导出401及HTTP跳转；不会初始化、登录或调用模型。TLS/网络失败即失败，不使用不安全证书选项。
5. 单独验证实际登录Cookie Secure/HttpOnly/SameSite、Origin/CSRF、邀请/恢复/撤销、刷新重入。未具备入口前，临时虚构库中的合成HTTPS Cookie测试不能冒充公共证书或微信验收。

回退：管理员只撤该站点/相关入站变更；应用停本用户unit、恢复原unit和私密配置、指回原数据目录，重新daemon-reload/start并核对健康；不覆盖任何运行库、不删虚构库/正式库/备份。备份/监测需同步恢复到匹配根路径及数据库，先手动backup/restore-check/check成功后启用timer。

## 正式家庭切换和私密交付

旧空间确认仍为虚构后，只准备全新配置/目录，不沿用虚构管理员或令牌。入口验证及家长明确启用后，先保全原库和全部有效备份，再切候选unit；同步备份/监测到正式库及独立目录。未首次初始化的正式DB不能拿来运行备份命令冒充成功，家长建家后立即实际backup/restore-check/check并启用定时任务。

管理员首次入口与BOOTSTRAP_TOKEN只能在现有私密SSH终端交付，不在聊天/Git/日志输出。家长填写并确认当前档案后，由管理员私发单次邀请给第二位家人。使用同一HTTPS网址收藏；换设备可由管理员生成原成员恢复链接。禁止从旧聊天自动填月龄、过敏或成员信息。

异机加密还需用户给出本项目独立存储位置与最小权限安全身份、加密接收方公钥及恢复私钥保管方式；取得后由执行者验证加密上传→下载→解密→隔离恢复，不动量化存储，不把本机明文副本称为灾备。
