## 首次配置与启动

以下命令由已有ECS连接的执行者运行，不要求用户重复手工操作。先核实独立目录、端口和资源；新检出时将完整SHA作为该次发布标识，不在发布中途跟随main变化。

```bash
# 进入核实过的独立源码目录后；只在没有.env时执行。
python3 scripts/deploy.py configure --non-interactive --mode private
python3 scripts/deploy.py check

docker compose -p family-parenting-agent build
docker compose -p family-parenting-agent up -d
docker compose -p family-parenting-agent ps
curl --fail --silent --show-error http://127.0.0.1:18080/api/health
```

`configure --non-interactive`不提示输入、不访问网络、不读取其他项目配置：随机生成新的初始化凭证，固定应用库/data/family.sqlite3、关闭演示，.env权限600且拒绝覆盖或符号链接。未配置密钥时模型不启用，手工记录可部署。不要把.env当Shell脚本source执行，也不要将真实密钥拼入shell命令。

它只从执行进程读取PUBLIC_ORIGIN、MODEL_API_KEY、MODEL_BASE_URL、MODEL_ID、MODEL_ENABLE_THINKING、MODEL_DAILY_REQUEST_LIMIT、PANTRY_RECONFIRM_DAYS；不会读取量化专属变量、沿用BOOTSTRAP_TOKEN或接受APP_DB覆盖。密钥为空时不因此向用户索要；先完成无模型阶段。有真实项目配置则保留并验证，不能因为脚本拒绝覆盖而删除.env再建。

已有有效HTTPS入口时，改用`--mode production`，必须事先安全配置PUBLIC_ORIGIN。生成后PRIVATE/PRODUCTION之间不会自动切换；升级时编辑本项目配置并重新创建容器，保留原卷。服务端.env、进程环境和SSH会话之间不会自动共享设置，配置检查只证明字段与资源，不证明代理或模型已可用。

## 真实模型执行

只在本项目密钥已安全配置、镜像已构建后执行：

```bash
docker compose -p family-parenting-agent run --rm --no-deps app python scripts/check_model.py --call-model
docker compose -p family-parenting-agent run --rm --no-deps app python scripts/evaluate.py --cases r01,r03,m01,p01 --call-model --max-calls 4
```

第一次测试最多1次请求；核心评测最多4次，调用失败不自动提高上限。评测报告在/data/evaluations内私密保存，工具只用自己的虚构临时库。若确实需要并且前4条结果可接受，再用--all和显式上限评测其余场景；不要反复盲跑--all。此次数上限不是人民币费用硬封顶，也不计入应用内家庭每日额度；必须记录实际使用量，供应商账户预算另行核实。模型输出仍需家长核对，不自动发布菜单或修改档案。
